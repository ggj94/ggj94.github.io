Groundwork privacy policy

Last updated: 28 October 2026

Groundwork is a private reporting tool operated by Gent Gjonbalaj (contact: gent.gjonbalaj@gmail.com). It is used only for the businesses he manages.

What it accesses

When the account that manages a Google Business Profile authorises Groundwork, it reads that profile's details and performance figures (for example calls, direction requests, website clicks, views and search terms) through the Google Business Profile APIs.

How the data is used

The data is used only to report on and improve the local search presence of the business it belongs to. It is stored in a private repository and shown on a private dashboard. It is not sold, shared with third parties, or used for advertising.

Google user data

Groundwork's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions. To have stored data deleted, email gent.gjonbalaj@gmail.com.
